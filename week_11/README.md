# Week 11 Portfolio

This repository contains the Week 11 SQL and Python exercises completed as part of the FinTrust Cloud Portfolio.

## Folder Structure

```text
fintrust-cloud-portfolio/
└── week_11/
    ├── python/
    │   ├── python_concurrency_practice.py
    │   └── python_decorators_practice.py
    │
    └── sql/
        ├── cte_recursive_queries.sql
        └── window_functions_practice.sql
```

## Contents

### Python Exercises
Located in the `python/` folder:

- `python_concurrency_practice.py`
  - ThreadPoolExecutor examples
  - Asyncio examples
  - Concurrency benchmarking
  - Sequential vs parallel execution comparisons

- `python_decorators_practice.py`
  - Timer decorators
  - Retry decorators
  - Decorators with arguments
  - Logging and memoization decorators

### SQL Exercises
Located in the `sql/` folder:

- `cte_recursive_queries.sql`
  - Common Table Expressions (CTEs)
  - Chained CTEs
  - Recursive CTEs
  - Multi-step analytical queries

- `window_functions_practice.sql`
  - Window Functions
  - Ranking Functions
  - LEAD and LAG
  - Running Totals
  - Partitioning and Ordering
