## Overview

Week 05 focused on AWS networking, connectivity, DNS, content delivery,
and cloud architecture. The week included practical work and
architecture diagrams covering Amazon VPC, network connectivity, Route

## Architecture

The `architecture/` directory contains the AWS architecture diagrams
created during Week 05.

### Diagrams

-   **Target Architecture** --- Final/target AWS architecture design.
-   **CloudFront Architecture** --- Architecture showing the use of
    Amazon CloudFront for content delivery.
-   **Day 2 Architecture** --- Architecture created during the Day 2
    networking and connectivity activities.
-   **Route 53 Architecture** --- Architecture related to DNS and Route
    53 configuration.

Both `.drawio` and `.svg` versions are included where applicable. The
Draw.io files can be edited, while the SVG files provide a
viewable/exported version of the diagrams.

## Learning Outcomes

By the end of Week 05, I developed a stronger understanding of how AWS
networking and content delivery services work together to support cloud
applications.

Key learning outcomes included:

-   Understanding the purpose and structure of an AWS VPC.
-   Understanding how AWS resources communicate through network
    connectivity.
-   Understanding DNS and how Route 53 can be used to manage domain
    resolution.
-   Understanding the role of CloudFront in delivering content
    efficiently.
-   Designing and documenting AWS cloud architectures.
-   Connecting individual AWS services into a broader cloud
    architecture.
-   Reviewing AWS concepts through mock examination preparation.

## Week 05 Summary

Week 05 strengthened my understanding of AWS infrastructure by moving
beyond individual cloud services and focusing on how networking, DNS,
and content delivery components work together. The architecture diagrams
and daily notes document the practical work completed throughout the
week and provide a reference for future AWS projects.
